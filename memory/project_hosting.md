Проект errani.ru хостится на **reg.ru cloud** (облачный VPS/сервер), НЕ на Vercel.

**Why:** Пользователь явно исправил — "почему vercel? у меня же регру клауд!"

**How to apply:** 
- При инструкциях по деплою/переменным окружения — говорить про reg.ru, не Vercel
- Переменные окружения скорее всего задаются в .env файле на сервере или через панель reg.ru
- Деплой через git pull на сервере или через панель управления reg.ru cloud
