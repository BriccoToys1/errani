- `GET /api/products` / `showAll=true` → каталог живой
- Карточки `/gothic-vibe-tarot` — галерея, цена, скидка, CTA
- Добавление в корзину, шаг оформления (контакты + адрес)

- Admin login, Аналитика (цифры грузятся), Почта (~99 диалогов), Заказы (список), Товары API (11)
